# AI Usage Disclosure

This is a hobby project. The majority of the code in this repository was
generated by AI tools — primarily Cursor with large language models (LLMs).

AI tools are used for code generation, scaffolding, refactoring, and
documentation. The typical workflow is: describe what is needed, let the AI
produce a first pass, then iterate by testing and refining.

## Oversight

Code is verified through functional testing ("does it build and do what I
expect?") rather than rigorous line-by-line review. The author takes
responsibility for what lands, but full provenance review of every AI-generated
line has not been performed.

## Contributions

This project welcomes human contributions. If you use AI tools while
contributing, note it in your pull request description.
