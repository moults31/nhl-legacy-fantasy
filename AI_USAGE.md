# AI Usage Disclosure

This project makes use of AI-assisted development tools, including large
language models (LLMs) accessed through Cursor and similar tools.

## How AI is used

- **Code generation and scaffolding** — AI tools help generate boilerplate,
  type definitions, schema translations, and repetitive patterns.
- **Refactoring and code review** — AI assists in restructuring code, flagging
  potential issues, and suggesting improvements.
- **Documentation and comments** — AI helps draft and refine READMEs, inline
  documentation, and developer guides.

## Human oversight

All AI-generated code is reviewed, tested, and validated by human contributors
before it is merged. No code enters the repository solely on the say-so of an
AI tool. Contributors are responsible for understanding every line they commit,
regardless of its origin.

## Contributions

This project welcomes human contributions. AI-generated contributions (e.g.
pull requests produced primarily by an LLM without meaningful human review)
are not accepted. If you use AI tools while contributing, please disclose
that usage in your pull request description and confirm you have personally
reviewed and tested the changes.
